## Stack

- Next.js 16 (App Router) com exportação estática (`output: "export"`)
- TypeScript e Tailwind CSS 4
- SEO: metadata, Open Graph, JSON-LD `Person`, sitemap e robots
- Deploy automático no GitHub Pages via GitHub Actions a cada push na `main`

## Rodar localmente

```bash
npm install
npm run dev
```

Os textos (projetos, serviços, experiência e stack) ficam em `src/data/perfil.ts`.
Os prints dos projetos ficam em `public/projetos/`.
